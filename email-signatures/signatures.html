Email signatures, built to survive Outlook's rendering engine.

How to use these

  1. Click Copy signature on the one you want.
  2. In Outlook: Settings → Mail → Signatures → New signature.
  3. Click into the editing box and paste with Cmd+V.
  4. Set it as the default for that account, for both new messages and replies.
  5. Repeat per account — each address gets its own signature.

If pasting strips the formatting, use Cmd+Shift+V or paste into the browser first, then copy from there. Never retype the address — a typo in a signature propagates to every email you send.
